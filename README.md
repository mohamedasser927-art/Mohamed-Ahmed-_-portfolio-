# Cybersecurity Portfolio

## Quick setup
1. Put your photo in the project folder and change the `photo-placeholder` in `index.html` to an `<img>` tag.
2. Replace `Your Name`, email, GitHub and LinkedIn.
3. Edit certifications and projects.
4. Open `index.html` in a browser to test it.
5. Upload the three files to a GitHub repository and enable GitHub Pages.

## Main files
- `index.html` — page content
- `style.css` — cyber/dark design
- `script.js` — mobile menu

## Recommended photo
Use a square portrait, preferably 600×600 px or larger.
